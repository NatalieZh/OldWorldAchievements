# Old World Achievement Guide

Интерактивный русскоязычный трекер и планировщик достижений для **Old World**.

## Текущее состояние

Стартовая стабильная версия для переноса в GitHub: **v23**.

База содержит **408 достижений Steam** и включает:

- ручное ведение прогресса;
- импорт/экспорт прогресса;
- каталог и фильтры;
- планировщик новой партии;
- Current Run;
- строгие связи с цивилизациями (`playerCivs`);
- мягкие связи (`affinityCivs`);
- национальные уникальные юниты;
- прозвища, их пороги и легитимность;
- Steam rarity;
- поля `Как получить` и `Оптимальная тактика`.

## Планируемая структура

```text
/
├─ index.html
├─ data/
│  └─ achievements.json
├─ docs/
│  ├─ audits/
│  └─ notes/
└─ README.md
```

На первом этапе важно сохранить поведение v23 без изменений. После переноса база будет отделена от интерфейса постепенно, отдельными проверяемыми изменениями.

## Ближайшие задачи

1. Перенести рабочую v23 в репозиторий.
2. Сделать подробную информацию достижения очевидно доступной из каталога и окна «Мои достижения».
3. Проверить отображение `Как получить` и `Оптимальная тактика`.
4. Доработать городские достижения и механику переименования городов.
5. Продолжить аудит данных и планировщика.
6. Подготовить GitHub Pages после стабилизации структуры.

## Важные правила данных

- Всего достижений: **408**.
- Нельзя дедуплицировать достижения только по русскому названию/условию.
- Официальные русские дубли могут быть разными Steam achievements.
- `playerCivs` означает строгую необходимость играть за цивилизацию.
- `affinityCivs` означает естественную/тематическую связь, но не обязательное требование.
- «Прозвище» используется вместо «когномен».
- `Чудо` и `Сооружение` остаются разными категориями.

## Источники

Для проверки механик используются прежде всего:

- Steam achievements;
- официальная Old World Wiki / Hooded Horse;
- подтверждённые игровые тесты;
- обсуждения сообщества — только как дополнительный источник для неочевидных механик.
