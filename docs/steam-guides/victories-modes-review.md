## Проверенные условия и оставшиеся вопросы

Проверены `achievement.xml`, `victory.xml`, `difficultyMode.xml`, `PlayerGoal.isAchievementComplete`, `PlayerGoal.isAchievementGameMode`, `Player.doStartAchievements`, `Game.checkVictory`, `Game.getVPToWinByVictory`, `Game.makeWinner` и `Game.isValidAchievement`.

Ключевые исправления: двойная победа — 50% обычного порога и 200% очков каждой живой команды; завоевание допускает капитуляцию и союзников при включённой победе союза; время допускает равенство ОП; семьи для «Ещё до монгольской орды» считаются текущие. У Hotseat стартовое достижение тоже требует многопользовательского признака. Дуэль и FFA требуют соревновательного мультиплеера, командный режим — `teams <= players / 2`. Для «Хардкора» `iNumOpponents=6` является нижней границей, а не точным числом.

Пари с городом a354 имеет выдающие скрытые события для нескольких победных исходов; полный маршрут возникновения пари и перенос его метки между владельцами в этой сверке не воспроизводился. Этот совет остаётся маршрутом для проверки, а не гарантированной последовательностью. Ничья ОП для победы по времени тоже требует игрового теста порядка определения победителя; текст рекомендует уверенное преимущество.
