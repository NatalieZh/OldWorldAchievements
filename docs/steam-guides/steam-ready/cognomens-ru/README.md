# Прозвища правителей: файлы для Steam

## Название

Old World: достижения за прозвища правителей

## Краткое описание

Все достижения за прозвища правителей: легитимность, пороги, способы набора очков и советы. Прозвища сгруппированы по легитимности; полная база и планировщик доступны по ссылке в начале руководства.

## Разделы

Каждый файл содержит текст одного раздела в разметке Steam. Название раздела вводится отдельно; номера в именах файлов в Steam не добавляются.

| Раздел | Файл |
|---|---|
| Полный каталог и планировщик | [01-catalog.txt](01-catalog.txt) |
| Как работают прозвища | [02-how-it-works.txt](02-how-it-works.txt) |
| Легитимность 10–30 | [03-legitimacy-10-30.txt](03-legitimacy-10-30.txt) |
| Легитимность 40 | [04-legitimacy-40.txt](04-legitimacy-40.txt) |
| Легитимность 50 | [05-legitimacy-50.txt](05-legitimacy-50.txt) |
| Легитимность 60 | [06-legitimacy-60.txt](06-legitimacy-60.txt) |
| Легитимность 70–100 | [07-legitimacy-70-100.txt](07-legitimacy-70-100.txt) |
| Почему прозвище не появляется | [08-troubleshooting.txt](08-troubleshooting.txt) |
| Источники | [09-sources.txt](09-sources.txt) |

Дата последней проверки и ссылка на сайт находятся в первом разделе. Названия прозвищ оформлены подзаголовками; они не являются отдельными разделами правого меню. Оглавление формирует Steam.

Внутри каждой записи заголовок, легитимность, очки и совет идут подряд без пустых строк. Между соседними прозвищами оставлена одна пустая строка.

Подготовлено 9 разделов и 56 прозвищ. Перед публикацией проверь предпросмотр, переносы строк и актуальность даты проверки.
