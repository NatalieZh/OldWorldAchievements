# Персонажи, отношения и события: файлы для Steam

## Название

Old World: достижения за персонажей, отношения и события

## Краткое описание

33 достижения Old World: персонажи, отношения, семья, события и особые цели. Условия и советы с учётом дополнений.

## Разделы

Каждый файл содержит текст одного раздела в разметке Steam. Название раздела вводится отдельно; номера в именах файлов в Steam не добавляются.

| Раздел | Файл |
|---|---|
| Полный каталог и планировщик | [01-catalog.txt](01-catalog.txt) |
| Черты и происхождение | [02-traits.txt](02-traits.txt) |
| Дипломатия и отношения | [03-diplomacy.txt](03-diplomacy.txt) |
| Семья и двор — часть 1 | [04-family-01.txt](04-family-01.txt) |
| Семья и двор — часть 2 | [04-family-02.txt](04-family-02.txt) |
| Встречи и события дополнений — часть 1 | [05-events-01.txt](05-events-01.txt) |
| Встречи и события дополнений — часть 2 | [05-events-02.txt](05-events-02.txt) |
| Особые цели державы и религии — часть 1 | [06-special-goals-01.txt](06-special-goals-01.txt) |
| Особые цели державы и религии — часть 2 | [06-special-goals-02.txt](06-special-goals-02.txt) |
| На что обратить внимание | [07-tips.txt](07-tips.txt) |
| Источники | [08-sources.txt](08-sources.txt) |

Steam формирует оглавление по названиям разделов. Названия достижений оформлены подзаголовками.

**Важно:** это подготовка для предпросмотра. Событийные цепочки и отдельные условия ещё требуют проверки перед публикацией; подробности — в [characters-review.md](../../characters-review.md). Дата в первом разделе — дата подготовки, а не подтверждение полной проверки.

## Размер разделов

Рабочий предел для переноса — 6000 символов и 6000 байт UTF-8 на раздел, включая BBCode. Это запас для редактирования, а не подтверждённый лимит Steam. Длинные разделы разделены по подзаголовкам; записи достижений сохранены целиком. Дата проверки игровых условий от этого разбиения не меняется.
