Установленная игра: `C:/Program Files (x86)/Steam/steamapps/common/Old World`, build **26728102** по манифесту Steam. [Источник каждого ID и контрольные суммы](carthage-source-index.json). Индекс автоматически находит записи; сам по себе он не доказывает тактику. Ниже перечислены прочитанные проверки и границы выводов.

[Публичный список Steam](series-steam-check.json) содержит 408 записей на русском, полученных 26 ноября с явно заданным языком; все нужные API ID найдены. Официальные названия и условия сохранены в тексте. Сходные названия и разные ранги не объединены.

## Проверенные условия и оставшиеся вопросы

Проверены `scenario.xml`, `CarthageCampaignGame.checkVictoryLevel`, `checkVictory`, `getMaxTurns` и `globalsInt-add.xml` всех четырёх модулей. Пороги 6/8/10/12 одинаковы во всех четырёх главах; лимиты 100/100/60/80 ходов. Имена достижений рангов строятся динамически из ID сценария: отсутствие прямого литерала API ID в коде не означает отсутствие источника. Четвёртый сценарий включает достижение кампании в список наград без отдельного пересчёта предыдущих глав.

Кампания доступна как сценарный контент основной игры; метка `Carthage campaign` в базе является её группировкой, не отдельным покупаемым DLC. В этой работе она не переименовывается, чтобы сохранить действующий фильтр приложения.

Конкретные решения всех случайных целей и оптимальный маршрут к 12 целям не проходились. Рекомендация следить за журналом целей не означает, что любой набор решений сохранит достижимость эпической победы.
