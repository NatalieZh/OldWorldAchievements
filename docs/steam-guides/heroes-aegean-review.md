## Проверенные условия и оставшиеся вопросы

Проверены сценарные модули Greece1–Greece6: бонусы выдачи, связывающие события/варианты, цели, фильтры и ключевые методы кода. DLC подтверждено `additionalContent.xml` (`CAMPAIGN_GREECE`) и регистрацией сценарных модулей.

Марафон: цели блокады/гонца/битвы имеют 3/5/7 ходов. Фермопилы: код выдаёт достижения на счётчиках 10/20/30/40/50, безупречный Саламин сравнивает исходное и оставшееся число кораблей.

Филипп: `doVictoryLevel` считает выполненные `GOAL_DOMINATE_SPARTA`, `GOAL_TAKE_ILLYRIA` и уничтоженное фракийское племя. Одно условие даёт серебро, два — золото; бронза выдаётся всегда при победе. Старый набор «Иллирия, брак, Олимпиада» неверен. Для двух фракийских городов проверяются ID 2 и 3, не переименование. Олимпийское достижение вызывается завершением цели проекта, без отдельной проверки победы в скачках.

Олимпиада: три победных истории требуют разные `MemoryPrereq`; дерево интриг проверяется при исследовании через остаток единственной доступной возвращаемой технологии. Не обещается необходимость сначала завершить бесконечную конечную карту. Для политического достижения используется специальный триггер окончания влияния; точный оптимальный порядок всех решений не воспроизводился.

Александр: `doVictoryAchievement` использует `turn <= 60` и `turn <= 50`, для высшего ранга дополнительно `TRAIT_PHARAOH`. Гордион выдаёт достижение общим бонусом события до отдельного ответа. Для преемников проверены фильтры стороны и цепочка победного события.

Практически не перепройдены три линии заговора Олимпиады и каждый вариант морских/сухопутных боёв. Перед авторской проверкой сохранять отдельные прохождения; рекомендации о тактике не означают гарантированный безошибочный маршрут.
